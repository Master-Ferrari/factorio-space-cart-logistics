# Каретка hp — хайполи по блокингу v9c

Форма, размеры и механизм те же, что в одобренном блокинге [v9c](../v9c/) (референс, его не трогаем). Изменилось только качество поверхности: модель сделана под хардсюрфейс по принципу «рационального инженера, у которого немного станков».

```
python make.py                    # build → render → compose (~1.5 мин)
python make.py --from render --views close     # только крупные планы
python make.py --from compose
```
Результат: `out/sheet.png` (формат листа v9c), `out/sheet_close.png` (крупные планы: v9c и hp), `out/metrics.json`, `cart_hp.blend`.

## Стандартные радиусы (`params.RADII`, 1 BU = 1 тайл)
| радиус | значение | сегм. | профиль | где |
|---|---|---|---|---|
| гиб `bend` | 0.022 | 4 | 0.5 (дуга) | все рёбра гнутой обшивки корпуса; углы контура резки (щёки, рёбра жёсткости) |
| галтель `fillet` | 0.008 | 3 | 0.5 | вогнутые углы: сварной шов, галтель фрезы в выемках и кармане, уступы точёных деталей |
| кромка `edge` | 0.004 | 2 | 0.6 | выпуклые углы: торец листа, наружный угол уступа точёной детали |
| фаска `chamfer` | 0.002 | 2 | 0.7 | мелочь: пальцы, оси, колпачки, пины, таблички, полосы |

При 256 px/тайл 0.004 ≈ 1 px; в игре (64 px/тайл) читается только гиб.

## Номенклатура производства
- **Лист с гибкой** — обшивка корпуса: один гнутый лист, все рёбра гранёного ящика — гиб R 0.022. Утопленные панели крыши и скатов — штамповка, кромки — кромка/галтель. Отступы панелей расширены (`ROOF_IN` 0.032, `FACADE_IN` 0.034 вместо 0.016/0.02), чтобы гиб на них не налезал.
- **Лист с резкой** — щёки и рёбра жёсткости: углы контура — R гиба, торцы листа — кромка. Таблички и полосы — фаска.
- **Токарка** — обод с конической кромкой, диск, ступица (восьмигранник: лыски под ключ), ось, колпачок, палец шарнира, кулаки и проушины (теперь круглые, 48 сегментов), чашки пружины, гильзы и пины контактов. Уступы: кромка снаружи, галтель внутри.
- **Гнутая труба** — бампер, опора, заглушки: гладкие тела, без фасок.
- **Навивка** — пружина: круглая проволока (в v9c квадратная), гладкая.
- **Фрезеровка** — выемки под захват и карманы пружин (булевы, запекаются в меш корпуса): галтель в углах, кромка по краю.

## Техника
- `classify()` в `build.py` размечает рёбра весами `bw_bend` / `bw_fillet` / `bw_edge` по излому больше `SHARP_DEG` = 30° и выпуклости. Стек модификаторов: Bevel(bend) → Bevel(fillet) → Bevel(edge), все по атрибуту (`edge_weight`), затем Weighted Normal (Face Area, Keep Sharp). Шейдинг сглаженный. Модификаторы не применены, сетка годится под запекание на лоуполи.
- **Грабли:** `miter_outer = MITER_ARC/PATCH` на галтелях после булевых даёт выброс вершин в бесконечность (1e14). Дуговая митра стоит только у гибов.
- Крупные планы (`render.py`, вид `close`) — Workbench: цвета материалов и матк­ап `hard_surface_grey.exr` на сером. Блокинг v9c подключается связанной коллекцией из `../v9c/cart_v9c.blend` (только чтение).

## Метрики
Силуэт не изменился: dy среднее −18.8 px (v9c −18.9), от −21.9 до −16.4; высота рамки 58…69 px — как в v9c.

## Открыто
- Сварные швы между отдельными деталями (ребро ↔ корпус, опора бампера ↔ корпус и труба, рейки ↔ крыша) не моделированы: галтель есть только внутри одного меша. Валик шва — отдельная развёртка по линии контакта, в игре не виден (≤ 2 px при 256).
- Ступица осталась восьмигранной (мотив рельса), а кулаки шарнира стали круглыми.
