# Фильм: поиск формы каретки

Слайдшоу из реплик автора (дословно, с рисунками) и листов, которые получались в ответ. Опубликовано артефактом: https://claude.ai/artifact/SayvcHtqaDSCVDR4FvfrgS (страница `artifact.html`, листы в `img/`).

Две колоды на одной странице:
- **Синхрон.** Слева реплика автора, справа игровой масштаб и модель курсом E-W в 256 px и 64 px ×4.
- **Полные листы.** Реплика и результат идут попеременно.

## Файлы
| что | где |
|---|---|
| хронология (реплики дословно + ссылки на листы и панели) | `src/timeline.py` |
| сборщик | `src/build_film.py` → `artifact.html`, `index_full.html`, `index_sync.html`, `img/` |
| данные, которые не лежат в папках вариантов: картинки автора, перезаписанные листы, панели синхрона | `data/` |
| реплей правок агентов по их транскриптам (так восстановлены v9c и v6 v1) | `src/replay.py`, `src/replay_gen.py`, `src/extract.py` |
| скрипты каждого промежуточного состояния v9c | `v9c_states/` |
| что уже загружено в артефакт | `published.json` |

`img/` — выход сборки, в гит не идёт.

## Как дописать шаг
1. **Реплика автора.** Сохранить её дословно, картинки положить в `data/images/`.
2. **Результат.** После каждой итерации, которую видел автор, снять снимок, пока его не перезаписали:
   - лист — `data/frames/<имя>.jpg`;
   - панели синхрона — `python src/panels.py <папка варианта> <ключ> data/panels/<имя>`. Это `_game`, `_ew256`, `_ew64`; работает для конвейера v5b и его наследников, где есть `compose.game_view` и вид `single`.
3. Добавить шаг в `STEPS` в `src/timeline.py`.
4. Собрать: `python src/build_film.py`.
5. **Опубликовать.** Republish `artifact.html` по тому же URL. В `files` передать только картинки из `img/`, которых нет в `published.json`, затем дописать их туда.
   - За одну публикацию — до 64 МБ.
   - Имена в `img/` зависят от порядка в хронологии. Шаги дописывать только в конец, иначе имена уже загруженных картинок сдвинутся.
