# Каретка hp2 — хайполи с нуля

Построена только по рендерам v9c (лист, ортовиды, правки автора 11–16). Модель лоуполи не читалась.
Пересборка: `python make.py [--from build|render|compose] [--views close,...] [--film NN]` (~1 мин).

## Файлы
- `hk.py` — хайполи-кит (перенос из death-world-marathon `lowkit.py` / `helm_b`): `polytope` (выпуклое тело
  плоскостями, без булевых), `prism`, `hull`, `lathe` (профиль замкнут на оси), `round_profile` (явные галтели
  токарного профиля), `sweep`, `bevel`, `boolean` (EXACT, одна оболочка), `join`, `rs` (воксельный ремеш + Smooth).
- `build.py` -> `cart_hp2.blend` (коллекция `CART_A`, исключена; корень `CART_A_root`).
- `render.py`, `compose.py` — конвейер v9c, плюс вид `close` (matcap `hard_surface_grey` и зебра).
- `out/sheet.png` — лист формата v9c; `out/close.png` — крупные планы рядом с v9c.

## Проход 2 (отзыв автора на hp2_01)
- Короб — жесть: продольные выштамповки крыши (r 11) идут через гиб на скаты торцов и кончаются над выемкой;
  поперечные выштамповки бокового ската обрамляют карман пружины; по самому широкому поясу — отбортовка-фальц.
  Отдельной крышки нет: рёбра — часть листа (один ремеш, галтели).
- Торец — один скат от площадки до низа шатра (z 0.413): на виде с торца шестигранник целиком.
- Выемка хвата: прямые отрезки, фаски верхних углов, бока сходятся книзу, бока скошены, нижняя кромка R 0.09.
- Пого-контакты — на скате торца под выемкой; таблички — на крыльях щёк, обе стороны крыла.
- Пружина ушла в тело короба: карман вдоль её оси, упор у площадки, внутренность кармана тёмная.
- Бампер — голая труба, без накладок. Колесо толще (75 мм) внутрь, как у v9c.
- На листе — наложение силуэтов hp2/v9c в 6 ракурсах с долей расхождения.
- Прошлый лист: `out/sheet_01.png`, `out/close_01.png`.

## Технология
| деталь | как сделано | радиус |
|---|---|---|
| корпус | короб + шатёр (`polytope`), bevel, union, карманы и выемки boolean, хомуты и проушины приварены, ремеш 2.2 мм + Smooth ×4 | гиб шатра 14, короб 10, фреза кармана 14, выемка 12 |
| колесо | токарное, без ремеша, галтели в профиле, затенение по углу 30° | обод 9, конус/проточка 2–4 |
| щека | лист 20 мм + отбортовка верха + петля r 23 на пальце + литой узел оси, ремеш 1.4 мм | кромка 4 |
| бампер | труба r 30 по дуге + литой кронштейн, ремеш + Smooth ×8 | кронштейн 10 |
| гайки, болты | 8/6 граней, bevel, затенение по углу 40° | 1.5–3 |

## Иерархия и оси
`CART_A_root` -> `body` -> `cheek_L/R`: начало на оси пальца, качание вокруг Y -> `wheel_L/R`: начало в центре колеса,
вращение вокруг оси n = (∓0.707, 0, 0.707). Пружины, пальцы, гайки — дети `body`.

## Размеры (BU)
Корпус ±0.267 × ±0.40, z 0.341–0.608; колесо R 0.29, толщина 0.055, центр (±0.2275, 0, 0.231), конус 45°
вертикален на y = ±0.0225 (лезвие); палец в плоскости щеки, в 0.059 от колеса по оси.
